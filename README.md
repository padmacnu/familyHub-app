# Unitus: The Family Operating System

**Unitus** is a high-performance "Biological OS" designed to regulate the neurochemistry and environmental health of the home sanctuary. Built with a professional UI Architect aesthetic, it transforms household management into a series of **Excellence Protocols** and **State-Shift Rituals**.

---

## 🎯 Mission Objective
The modern home often suffers from "Domestic Stagnation," where work-mode stress leaks into family time. Unitus provides a centralized dashboard to:

* **Trigger State-Shifts:** Use physiological resets (water, movement) to signal the brain to exit "Survival Mode."
* **Regulate Neurochemistry:** Strategically manage Cortisol, Dopamine, and Oxytocin through intentional rituals.
* **Monitor Family Sanity:** A dynamic feedback loop that identifies "Areas for Growth" without blame, tracking the collective **Family Sanity Level**.

---

## 🏗 System Architecture
Designed for speed, modularity, and high-contrast visual clarity:
* **Framework:** React (Vite)
* **Styling:** Tailwind CSS (Custom HPE-inspired Design System)
* **Architecture:** Component-based modular OS with a decoupled data layer.

---

## ⚡ Core Protocols

### 1. The Refresh Ritual
* **Biological Mechanism:** Vagus Nerve stimulation via intentional water exposure (Face/Feet wash or full Shower).
* **Objective:** A physiological "Hard Reset" to transition from "High-Alert Survival" to "Social-Safe Recovery."

### 2. The 15-Minute Shared Blitz
* **Biological Mechanism:** Collective high-impact physical activity to restore environmental order.
* **Objective:** Regulate dopamine levels and eliminate visual clutter, which acts as a constant subconscious stressor preventing deep brain recovery.

### 3. The Zero-Screen Sync
* **Biological Mechanism:** Face-to-face interaction without digital interference.
* **Objective:** Facilitate the production of Oxytocin (the bonding molecule) to rebuild trust and emotional safety.

---

## 👥 Role Identities
Unitus recognizes that every member of the unit has a unique frequency. Users can toggle identities to see their specific duties:

* **The Provider:** Visionary. Sets the baseline frequency and provides the physical sanctuary.
* **The Nurturer:** Heart of the home. Manages the nutritional and emotional wellbeing of the collective.
* **The Learner:** Legacy builder. Contributes energy and growth to the family unit's future.

---

## 📊 Family Reflection (The Sanity Mirror)
The app captures "Yes/No" selections on key family observations. 
* **Agreement for Improvement:** Checking a box identifies a growth area.
* **Sanity Score:** The global score drops when growth areas are identified, signaling a need for a collaborative "State-Shift."

## 🚀 Installation & Setup

1.  **Clone the Repository**
    ```bash
    git clone https://github.com/padmacnu/familyHub-app.git
    ```
2.  **Install Dependencies**
    ```bash
    npm install
    ```
3.  **Launch the OS**
    ```bash
    npm run dev
    ```
